# 💰 Expense Tracker Bot — Telegram Mini App

Полнофункциональный трекер расходов внутри Telegram. Без регистрации, без форм — ваш Telegram-аккаунт и есть учётная запись.

Пишете боту `кофе 350` — трата записана. Отправляете фото чека — AI сам всё распознает. Открываете мини-приложение — видите красивые графики и полную аналитику.

---

## ✨ Возможности

### Ввод расходов
- **Текстом** — `кофе 350`, `такси 900 работа`, `1200 продукты`
- **Фото чека** — отправьте фото, AI (Gemini) распознает сумму, описание и категорию
- **Автокатегоризация** — бот сам определяет категорию (Еда, Транспорт, Связь и т.д.)
- **AI-фоллбэк** — если локальные правила не уверены, подключается Google Gemini для точного определения категории

### Аналитика
- `/today` `/week` `/month` — текстовые отчёты прямо в чате
- **Web-панель (Mini App)** — интерактивные графики, разбивка по категориям и дням
- **Экспорт в CSV** — команда `/export` или кнопка в панели, файл открывается в Excel без проблем с кириллицей

### Управление
- Редактирование категории — кнопка под каждой записью
- Удаление с возможностью отмены (Восстановить)
- Настройка валюты (₽, $, €, ¥ и др.)

## 🤖 Google Gemini AI

Бот использует **Google Gemini 3.6 Flash** для двух задач:

1. **Распознавание чеков** — когда вы отправляете фото, Gemini анализирует изображение и извлекает сумму, описание и категорию. Никакого OCR — прямой анализ картинки нейросетью.

2. **Умная категоризация текста** — если локальные правила не могут определить категорию (возвращают «Другое»), бот спрашивает Gemini. Если текст — бессмыслица, бот вежливо сообщит, что не смог распознать трату, вместо того чтобы записывать мусор.

### Как получить ключ Gemini API (бесплатно)
1. Перейдите на [aistudio.google.com](https://aistudio.google.com)
2. Нажмите **Get API Key** → **Create API Key**
3. Скопируйте ключ и вставьте в `config.php`:
   ```php
   define('GEMINI_API_KEY', 'ваш_ключ_здесь');
   ```

> **Примечание:** Gemini API бесплатен для базового использования. Без ключа бот всё равно работает, но чеки не распознаются, а незнакомые слова попадают в категорию «Другое».

## 🛡 Безопасность

- **HMAC-SHA256** — Web-панель проверяет подпись `initData` от Telegram, подделать запрос невозможно
- **Изоляция данных** — каждый пользователь видит только свои траты
- **Секреты вне репозитория** — `config.php` в `.gitignore`, в репо лежит только `config.example.php`

## 🚀 Установка

### Требования
- PHP 7.4+ с расширениями `sqlite3` и `curl`
- HTTPS-домен (для webhook и Mini App)
- Telegram-бот (создайте у [@BotFather](https://t.me/BotFather))

### Шаги

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Lilonejont/expense-tracker-bot.git
cd expense-tracker-bot/tracker_php

# 2. Создайте конфигурацию
cp config.example.php config.php

# 3. Заполните config.php своими данными
nano config.php
```

**config.php:**
```php
<?php
define('BOT_TOKEN', '123456:ABC-DEF...');           // от @BotFather
define('WEBAPP_URL', 'https://you.com/index.html');  // URL Mini App
define('WEBHOOK_URL', 'https://you.com/bot.php');    // URL вебхука
define('GEMINI_API_KEY', 'ваш_ключ');                // от aistudio.google.com
define('DB_FILE', __DIR__ . '/expenses.sqlite');
define('DEBUG_MODE', false);
```

```bash
# 4. Загрузите файлы на HTTPS-сервер

# 5. Установите вебхук
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://you.com/bot.php"
```

> База данных создастся автоматически при первом запросе.
